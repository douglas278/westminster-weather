# Westminster Weather

A live weather dashboard for Westminster, Colorado. The page loads data in your browser from the [National Weather Service](https://www.weather.gov/) and refreshes every 10 minutes.

**Site:** https://douglas278.github.io/westminster-weather/

- Current conditions from NWS station KBJC (Rocky Mountain Metropolitan Airport, Broomfield)
- 7-day and hourly forecasts from the NWS Boulder office (grid BOU/62,66)
- Active alerts for Westminster
- Denver (KFTG) radar loop

No API keys, no tracking, and no personal information. Add the site to a phone home screen from the browser share or install menu.

Data is provided by the National Weather Service. This is an unofficial page and is not affiliated with the NWS.
